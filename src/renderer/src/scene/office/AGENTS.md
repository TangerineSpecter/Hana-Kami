# 像素角色修改入口

修改本目录角色造型前，先阅读 [办公室像素角色微调准则](../../../../../docs/design/pixel-characters.md)。它记录了本项目用户的视觉偏好与已撤回的方案，后续明确的用户要求优先。

- 以菲伦的比例和实际观感作参考：脸部紧凑、脸颊适度收拢、下巴圆润、表情轻柔。
- 默认只改用户指出的部位，保留现有角色辨识度，不把局部调整扩展成整体重画。
- 不强制统一原始分辨率。可莉保留原版 64×96；本轮整体重画为 32×48 的方案已被用户否定并撤回。
- 避免脸部深色围边像胡子、脖子像第二张嘴，以及背面工作帧重复画手。
- 修改后生成并检查真实预览；代码检查通过不等于用户认可造型。
